# Contributing to Arthos

Contributions are welcome! Because Arthos is dedicated to the public domain under the **Unlicense**, any contributions you submit are also released under the Unlicense.

## Guidelines

- Keep Arthos **super lightweight** — avoid heavy frontend frameworks or bloated native dependencies.
- Keep UI files self-contained in `ui/` so the binary remains a single portable executable.
- Run `cargo test` and `cargo clippy` before opening a pull request.
